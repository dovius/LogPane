LogPane

Everything runs locally in your browser. No data leaves the page.

Open automatically

On these domains LogPane replaces Kubernetes / OpenShift “Raw” pod log pages (/api/kubernetes/api/v1/namespaces/…/pods/…/log) automatically. Chrome asks for access to each domain once. Only https:// domains (and localhost) can be added. Without this, click the toolbar button on a Raw page.

    Other ways to open logs

    Click the toolbar button on any other page to open the file viewer: drop downloaded .log files or paste log text. To open local files directly from file://, enable “Allow access to file URLs” on the extension’s details page.
